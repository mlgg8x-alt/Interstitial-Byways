# Interstitial Byways

NeoForge 1.21.1 mod that turns the Backrooms into fast travel, an exploration tool, and dimension traversal, replacing RTP and most portals.

- No required dependencies; other mods' dimensions are detected at runtime.
- Personal-use project. Reused Backrooms content is included with the original authors' permission.

## Status
Project scaffold only. Not yet built or tested.
