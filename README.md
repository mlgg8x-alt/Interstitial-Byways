# Interstitial Byways

NeoForge 1.21.1 mod that turns the Backrooms into fast travel, an exploration tool, and dimension traversal, replacing RTP and most portals.

- No required dependencies; other mods' dimensions are detected at runtime.
- Personal-use project. Reused Backrooms content is included with the original authors' permission.

## Build
Requires Java 21. `./gradlew build` writes `build/libs/interstitial_byways-0.1.0.jar`; drop it in the `mods` folder (NeoForge 21.1.235+).
Use `/interstitial enter` (op) to visit the dimension, craft a Transit Station to start a network.

## Status
Compiles and a dedicated server boots with the dimension generating. Gameplay is untested; see `PROJECT_STATUS.md`.
